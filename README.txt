ROYAL BUSINESS SUITE — GITHUB PAGES PACKAGE

FILES
- index.html: complete single-file browser app.
- README.txt: these instructions.

INSTALL ON GITHUB (PHONE OR COMPUTER)
1. Download this ZIP and extract it.
2. Open your existing GitHub repository for the site.
3. Upload index.html to the repository ROOT. If an index.html already exists, replace it.
4. Commit changes to the main branch.
5. Wait a few minutes, then open the GitHub Pages URL and refresh.

FEATURES INCLUDED
- Luxury responsive business dashboard
- POS / new sale and printable invoice
- Product catalog with SKU, cost, retail, wholesale, stock, low-stock alert
- Customer orders with status tracking and WhatsApp update link
- Customer directory
- Supplier directory
- Expenses and cashbook
- Reports: sales, cost estimate, gross profit, expenses, best sellers, payment method totals
- Online store preview and WhatsApp product ordering
- Store profile and exact original logo upload
- Export/restore full JSON backup and product export

IMPORTANT LIMITATIONS
This is a self-contained static HTML app. Business records and logo are stored only in the browser/device where you use it. They are not synchronized to other devices or visitors. It does not include secure owner login, shared cloud database, live inventory across customers, payment gateway, automatic WhatsApp sending, courier integration, or AI API. Those need backend/database accounts and configuration. Do not treat demo products/prices as actual stock or quotes. Replace them with real shop data.
