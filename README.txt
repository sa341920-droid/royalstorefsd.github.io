ROYAL MOBILE & PRINTING STORE — POS + FBR/TAX STARTER

Files:
- index.html: browser starter with POS checkout, cart, product/stock list, printable invoices, sales CSV, expense log, simple estimated sales/cost/expense summary, customer opening balances, tax records/export, JSON backup and restore.
- README.txt: instructions and limitations.

MANUAL START:
1. Extract ZIP.
2. Open index.html in Chrome to try it.
3. In GitHub, upload index.html to repository root if your account has write access.
4. Use your exact original black-and-gold logo through Settings. The original logo file is not embedded in this ZIP.

IMPORTANT:
- Data is local to one browser, not cloud-synced or secure multi-user storage.
- FBR/IRIS connection, return filing, FBR invoice numbers and live POS integration are NOT implemented.
- Tax records are not a filing/submission receipt. Verify applicable requirements with FBR/qualified Pakistani tax practitioner.
- Real payment gateways need approved merchant accounts and secure provider API integration.
- Automatic Facebook/Instagram publishing needs official authorization/API integration.
- Complete double-entry accounting, supplier ledgers, permissions, cloud database, and signed Android APK are not included in this starter and require further implementation/testing.
- Never put API secrets/passwords/OTP in front-end code or chat.
