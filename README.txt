INSTALL ON GITHUB PAGES
1. Download and extract this ZIP.
2. Open your GitHub repository for sa341920-droid.github.io.
3. Replace the repository's root index.html with this index.html.
4. Commit changes.
5. On your phone, open the website, refresh and if it still looks old, open Chrome menu > Settings > Site settings > Storage (or clear cached images/files) and reload; also try a private/incognito tab.

IMPORTANT
- This is a static GitHub Pages website. Manage changes are saved in the browser/device, not automatically published to all customers.
- WhatsApp checkout prepares an order message; the shop must reply to confirm the order. No card payment is collected.
