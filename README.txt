ROYAL MOBILE & PRINTING STORE — ONE-FILE GITHUB WEBSITE

The complete storefront (design, product catalogue, search, category filters, browser cart and WhatsApp order flow) is in index.html.

INSTALL:
1. Open your GitHub repository: sa341920-droid.github.io
2. Open index.html and choose Edit, or upload this index.html and replace the old one.
3. Commit changes. Wait a minute or two, then refresh the website.

ORIGINAL LOGO:
To preserve your exact official logo, upload your original logo image to the repository in a folder named assets, with filename logo.png. The website already looks for assets/logo.png. This package does not include the original logo because the actual logo image was not attached to this request.

LIMITS:
This is a static GitHub Pages website. The cart is saved only in the visitor's browser and checkout prepares a WhatsApp message. It does not process online card payments, share inventory between devices, or provide a server-side admin/order dashboard. Those need a backend or ecommerce platform integration.
